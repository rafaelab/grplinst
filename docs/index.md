# grplinst

`grplinst` is a CRPropa module for modelling the effect of plasma instabilities on electromagnetic cascades.

This documentation is a placeholder for the GitHub Pages site. It should eventually include installation notes, model descriptions, examples, and API references for the C++ and Python interfaces.

## Quick Build

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```
